# 題目

請講一次你收到嚴厲的回饋，以及你怎麼處理它。

## 核心答案

這題最容易失分的地方是選了一個太輕的批評——「有人說我文件寫得不夠詳細，我後來就寫詳細了」不足以展示任何東西；要選一個當下讓你不舒服的、關於你的工作方式或人際互動的回饋。

**好的答案有四段**：**回饋的具體內容**（要能複述對方的原話或大意）、**你當下的真實反應**（承認防禦或不服氣，那反而可信）、**你怎麼去驗證它是否成立**（問其他人、回頭看具體的事件）、以及你改變了什麼且怎麼知道有效。

**最有價值的是第三段**——「我一開始不服，所以我去問了另外兩位同事，其中一位給了我一個我完全沒印象的例子」；這展示了你會用證據檢驗對自己的批評，而不是只憑感受接受或拒絕。

**要避免的講法**：**「我立刻就接受並改正了」**（不真實）、以及批評的內容其實是變相的優點。

## 詳細解析

「當下的反應」誠實一點反而加分：沒有人在被批評時是不介意的——而說「我當下有點防禦，回家想了一個晚上才比較能客觀地看」比「我很感謝這個回饋」真實得多；面試官聽過太多標準答案，一點真實的情緒反而讓故事可信。

「驗證」是把回饋變成行動的關鍵一步：單一個人的回饋可能是誤解或者是對方的偏好——而「我問了另外三個人，其中兩個有同感」把它從一個人的意見變成了一個模式；這個動作也讓你的改變更有針對性，因為你會知道問題具體出現在哪些場合。

「改變什麼」要具體到行為的層次：「我變得更會溝通了」不是改變——「我開始在每次 code review 的評論裡先寫一句我理解的意圖，再提出疑問」才是；行為層次的改變可以被檢驗，而態度層次的宣稱不能。

「怎麼知道有效」是常被省略的收尾：「三個月後我主動問了同一個人，他說明顯有差」或者「後來的 review 討論從平均往返五次降到兩次」——沒有這一段，面試官無法區分「真的改了」與「說要改」；而主動回去問回饋者的動作，本身就是一個很強的信號。

## 面試回答方式

先指出最容易失分的是選了太輕的批評，再給四段的骨架。加分點有四個：誠實說出當下的防禦反應反而加分——**面試官聽過太多標準答案**；驗證是把回饋變成行動的關鍵一步，它把一個人的意見變成一個模式；**改變要具體到行為的層次**——行為可以被檢驗而態度的宣稱不能；以及**「怎麼知道有效」這個收尾**，主動回去問回饋者本身就是很強的信號。

## 講稿

我的前主管在一次一對一裡跟我說，你的 code review 讓資淺的同事不敢提交程式碼。

我當下的反應是防禦的。我心裡想的是，我指出的問題都是真的問題。回家想了一個晚上，我決定先去驗證。

我問了三位同事。其中一位給了我一個我完全沒印象的例子。他說我在一則評論裡寫了這個寫法有明顯的效能問題，而他當時花了兩天才搞懂我指的是什麼，因為我沒說是哪裡。

所以問題不在我指出的內容，在我的表達方式。我做了三個具體的改變。每則評論先寫一句我理解的意圖，把批評的對象從人換成程式碼。區分必須改跟建議，用不同的標記。還有超過兩則的問題就直接找人當面談。

三個月後我主動去問了那位同事。他說最大的差別是他現在知道哪些是一定要改的。而我們的 review 往返次數，從平均五次降到兩次。

## 常見追問

### 如果那個批評其實不成立呢？

**核心答案**：那也要先理解對方為什麼會這樣認為。即使事實不符，那個印象是真實存在的——而「為什麼他會得到這個印象」通常指向一個真實的溝通問題；所以正確的處理不是辯解也不是全盤接受，而是「事實我會澄清，但造成這個印象的原因我會處理」。

**詳細解析**：「印象和事實都是真實的，只是不同層面」：你可能確實在會議上發言了——但如果三個人都覺得你「不太參與討論」，那可能是你的發言時機、長度或者形式讓人記不住；而堅持「我明明有講」無法改變那個印象。這個區分在績效評估中特別重要——因為評價往往基於印象而非完整的事實記錄；而「主動管理別人對你的印象」不是政治手段，它只是承認「別人只能看到你展現出來的部分」。在面試中能表達這個理解，展示的是對職場現實的成熟認知——而它也預示了你不會是那種「我做了很多但沒人知道」然後感到委屈的人。

**面試回答方式**：給處理原則（事實澄清，但造成印象的原因要處理）。核心加分點是印象和事實都是真實的，只是不同層面，並用「明明有發言但被認為不參與」的例子說明。收在洞察：主動管理別人對你的印象不是政治手段，只是承認「別人只能看到你展現出來的部分」——這個認知預示了你不會成為「做了很多但沒人知道」然後感到委屈的人。

### 你會怎麼給別人批評？

**核心答案**：及時、具體、對事、私下，而且說清楚影響。「上週那個 PR 你在我提出疑問後直接合併了，我當時還沒理解那個改動的原因，這讓我後來 debug 時多花了時間」——這個結構包含了具體事件、你的觀察、以及造成的影響；**而它沒有對人下任何評語。**

**詳細解析**：**「回饋的時效性比措辭更重要」**：三個月後在績效評估中提起的問題，對方已經想不起來細節，也錯過了改進的機會——而當週提出的具體事件是可以討論的；所以「攢著一堆問題到年底一次講」是最糟的做法，它既無效又傷人。而給回饋的門檻應該低到「當下想到就說」——要做到這一點，回饋的形式必須輕：一句話、一則訊息、或者在一對一中花兩分鐘，而不是每次都要一場正式的談話。這個「把回饋變成日常而非事件」的文化，是高效團隊的共同特徵——而它需要的不是技巧而是頻率。

**面試回答方式**：給四個原則並示範一個完整的措辭結構（具體事件、觀察、影響、不對人下評語）。核心加分點是**回饋的時效性比措辭更重要**，並指出攢到年底一次講既無效又傷人。收在文化層面：給回饋的門檻應該低到「當下想到就說」，而要做到這點回饋的形式必須輕；把回饋變成日常而非事件，需要的不是技巧而是頻率。

### 如果公司沒有給回饋的文化呢？

**核心答案**：那就主動去要，而且要問得具體。「你覺得我做得怎麼樣」通常得到「還不錯」——而「如果我下一季要在一件事上進步，你覺得應該是什麼」或者「上次那個專案，如果重來一次你會建議我怎麼做不一樣」則能得到真實的內容；因為前者要求評價而後者要求建議，後者的心理門檻低得多。

**詳細解析**：「多數人不給回饋不是因為沒有意見，而是因為給回饋有社交成本」：擔心關係變差、擔心對方不接受、或者不確定該不該說——所以主動降低那個成本是有效的；明確地說「我真的想知道，你不用擔心我會不高興」並且在收到後表現出感謝而非辯解，會讓對方下次更願意說。而最有效的一次動作，是在收到一個尖銳的回饋後回去說「我照你說的做了，效果是這樣」——這證明了給你回饋是有用的，於是那個人會成為你長期的回饋來源。在一個沒有回饋文化的環境裡，你能為自己建立的最有價值的東西，就是兩三個願意對你說實話的人。

**面試回答方式**：給做法（**主動要，而且問得具體**）並對比兩種問法的效果差異。核心加分點是解釋多數人不給回饋是因為社交成本而非沒有意見，並給出降低成本的具體做法。收在長期價值：收到回饋後回去說「我照你說的做了，效果是這樣」會讓那個人成為長期的回饋來源；在沒有回饋文化的環境裡，兩三個願意對你說實話的人是你能建立的最有價值的東西。
