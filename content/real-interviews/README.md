# 實戰面試題（樣板類別）

InterviewHelpMe 第 12 個內容類別，共 50 題，是在前面已完成的 11 大知識類別基礎上額外建立的**「實戰應用」**題庫，把前面各類別已深入討論過的核心知識點和分析框架，**具體套用到真實公司常見的面試情境**裡。

## ⚠️ 題目來源與方法論說明（請務必閱讀）

本類別的每一題，都是**依照公開、可搜尋到的面試經驗分享（如牛客網、一亩三分地、Glassdoor、Blind、LeetCode Discuss，以及各種公開的技術部落格心得文等社群管道）整理、歸納出來的『代表性題型』**，用來反映**這家公司（或這一類型公司）在過去普遍被回報曾經考過的題目風格和技術重點**。

**這不是**：
- 某一場特定面試的逐字紀錄或官方認證內容
- 保證這家公司現在依然會用完全相同的措辭發問
- 由這些公司官方提供或審核的內容

**這是**：
- 依照公開的社群回報整理歸納而成的**代表性題型**，反映這家公司（或這一類型公司）**過去曾被廣泛回報考過**的技術主題和面試風格
- 用來幫助你**熟悉不同公司與地區的面試風格差異**，並**練習把基礎知識實際應用到具體情境**的素材

準備面試時，建議把這類題目當作**「風格參考和練習素材」**，而**不是**「一定會被逐字問到的題庫」。實際面試時，依然需要**依照自己應徵的具體職位，以及面試官當下的實際提問**靈活應對。

## 檔案格式

與其他類別相同：每題一個 `NNN-slug.md`，frontmatter 對應 [schema.sql](../../backend/sql/schema.sql) 的 `question` 表（`category: real-interviews`，`source: community`）。正文含：題目、核心答案、詳細解析、面試回答方式、常見追問（3 題）、相關。每題的 `title` 開頭都用 **【公司名稱】** 標示來源公司，`tags` 額外包含公司名稱和地區標籤。這個類別大量交叉連結回前面 10 大知識類別已深入討論過的核心概念（例如秒殺系統設計題連結回 Redis 分散式鎖、限流演算法、訊息佇列；跨行轉帳題連結回分散式交易、冪等性設計），這是刻意的設計——**這個類別的核心價值在於展現如何把基礎知識應用到真實情境，而不是重複講解已在其他類別深入解釋過的理論**。

## 涵蓋範圍

- **中國大廠（001-008）**：阿里巴巴、騰訊、字節跳動、美團、百度、京東、拼多多、網易——風格偏重手寫程式碼、高並發系統設計，以及對底層原理追問到極致細節
- **台灣本地公司（009-016）**：台積電資訊處、聯發科、國泰金控、中華電信、新創（91APP 等）、LINE Pay/街口支付、玉山銀行——風格偏重務實的實務經驗，以及金融科技領域特有的一致性、冪等性與資安考量
- **歐美外商/FAANG（017-024）**：Google、Meta、Amazon、Microsoft、Uber——風格偏重 System Design 的規模估算與權衡取捨、物件導向設計，以及結構化的行為面試（STAR 框架、Leadership Principles、Googleyness）

第二批（025-050）沿用同樣的三分區並各自加深：

- **中國大廠（025-032）**：小米、滴滴出行、快手、螞蟻集團、華為、嗶哩嗶哩、攜程、小紅書——從「單一元件怎麼做」推進到「大規模扇出、長連線的作業系統極限、帳務的複式記帳、推薦流的分層漏斗」這類需要一路追問到底的題目
- **台灣本地公司（033-040）**：富邦金控、趨勢科技、和泰／裕隆、緯創／廣達、KKday、Gogoro、蝦皮台灣、中租／裕融——涵蓋金融批次視窗、資安的大規模特徵比對、車聯網與工業物聯網、多供應商整合、大促流量，以及「既有單體要不要拆」這個台灣傳統產業最常見的架構題
- **歐美外商/FAANG（041-050）**：Netflix、Airbnb、Stripe、Dropbox、X/Twitter、Google、Meta、Amazon、Microsoft——以完整的 System Design 經典題為主（串流、帶日期的搜尋預訂、冪等支付 API、檔案同步、名人扇出、分散式限流、告警去重），並以 048 的行為題與 050 的「四十五分鐘怎麼分配」收尾
