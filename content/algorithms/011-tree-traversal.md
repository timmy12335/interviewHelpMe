# 題目

前序、中序、後序的真正差別是什麼？什麼樣的題目非用後序不可？

## 核心答案

三種深度優先遍歷的差別不是「根在前中後」這個口訣，而是**你在哪個時機處理這個節點**：**前序**是「**還沒進子樹就處理**」，適合把資訊**從上往下傳**（傳遞路徑、深度、父節點的累積值）；**後序**是「**兩棵子樹都回來了才處理**」，適合把資訊**從下往上收**（子樹高度、子樹節點數、子樹是否平衡、最大路徑和）；**中序**的特殊性在於二元搜尋樹的中序遍歷結果遞增，所以驗證 BST、找第 k 小、把 BST 轉有序串列都靠它。**層序**（BFS）用佇列，適合處理「按層」的需求——最小深度、每層最大值、鋸齒層序、以及最短路徑類問題。判斷準則一句話：需要子樹的結果才能算出自己的答案，就用後序；把狀態往下帶，就用前序。

## 詳細解析

**後序是「樹形動態規劃」的載體**：大多數看起來困難的樹題本質上都是後序——每個節點向左右子樹要一個「回報值」，用這兩個回報值算出自己的回報值往上傳，同時**順便更新全域答案**。二元樹的直徑就是典型：遞迴回傳的是「以該節點為端點向下的最長路徑」，但答案更新用的是「左邊加右邊」。這個「回傳的東西和答案不是同一個」是這類題最大的難點，也是面試官最愛追問的地方。最大路徑和同理——回傳時只能選一邊（因為往上走不能分岔），更新答案時可以左右都取。

**前序的用途是把上文帶下去**：求根到葉的所有路徑、路徑總和、判斷路徑是否遞增，這些都需要在進入子樹前就把當前狀態加進去，出來後撤銷——所以前序遍歷加上撤銷，本質就是回溯。另一個典型是「用父節點資訊修改子節點」（例如把每個節點改成從根到它的累加和）。

**迭代寫法的三種難度**：前序最簡單——用堆疊，彈出節點後**先壓右再壓左**（因為堆疊後進先出）。中序次之——用一個指針一路往左壓進堆疊，彈出時處理，然後轉向右子樹。後序最難，因為要確認右子樹已經處理完；常見技巧是用前序的變形（根右左）再整個反轉得到左右根，或者記錄「上一個被處理的節點」來判斷右子樹是否已完成。面試中被要求寫迭代，通常就是在測你是否理解遞迴堆疊在做什麼。

**Morris 遍歷做到 O(1) 空間**：一般的遞迴或迭代都要 O(h) 空間（h 是樹高）。Morris 遍歷利用葉節點的空右指標暫時指回中序後繼，走完再還原，把空間降到 O(1)。它的代價是會**暫時修改樹的結構**，在多執行緒環境或樹不可變的情況下不能用。這題屬於加分題，不必主動深講，但被問到時要能說出核心做法與代價。

**層序遍歷要「一次處理完一層」**：直接用佇列會把所有節點混在一起，分不出層。標準做法是在每輪迴圈開始時**先記錄當前佇列長度 size**，然後只處理 size 個節點——這 size 個就是同一層。有了這個骨架，每層最大值、鋸齒順序（用雙端佇列或每層反轉）、右視圖（每層最後一個）都是同一段程式的小改動。

## 面試回答方式

不要背口訣，直接說出判準——需要子樹的回報才能算自己的答案就用後序，要把狀態往下帶就用前序，二元搜尋樹相關就想中序。接著主動舉一個後序的例子（直徑或最大路徑和），並點出這類題的難點是回傳值和全域答案不是同一個東西，這句話最能證明你真的懂。層序遍歷主動說出「先記 size 再處理一層」這個骨架，並說明它讓每層最大值、右視圖、鋸齒順序都變成小改動。加分點是迭代後序的兩種做法，以及 Morris 遍歷能做到 O(1) 空間但會暫時改動樹結構。

## 講稿

三種遍歷的差別，重點不是根在前面中間還是後面，而是我在哪個時機處理這個節點。

前序是還沒進子樹就處理，所以適合把資訊往下帶，像路徑、深度、從根累積下來的值。後序是兩棵子樹都回來了才處理，適合把資訊往上收，像子樹高度、節點數、平衡判斷。中序的特殊性在於，二元搜尋樹的中序結果是遞增的，所以驗證 BST、找第 k 小都靠它。

我判斷用哪一種，就問一句話，我需不需要子樹的結果才能算出自己的答案。需要就用後序。

後序其實是樹形動態規劃的載體。每個節點跟左右子樹各要一個回報值，算出自己的回報值往上傳，順便更新全域答案。這裡最容易卡住的地方是，回傳的東西跟答案常常不是同一個。像二元樹的直徑，回傳的是往下的最長單邊路徑，但更新答案的時候是左邊加右邊。

層序的話我會用佇列，但每一輪先記下當前的佇列長度，只處理這麼多個節點，這樣才分得出層。有了這個骨架，每層最大值、右視圖、鋸齒順序都只是小改動。

## 常見追問

### 怎麼驗證一棵樹是不是二元搜尋樹？只比較節點和左右孩子夠嗎？

**核心答案**：不夠，這是最經典的陷阱。只比較「左孩子小於自己、右孩子大於自己」只保證了**局部**性質，但 BST 要求的是**整棵左子樹都小於自己**。反例是根為 10、右孩子為 15、而 15 的左孩子為 5——每一對父子關係都合法，但 5 出現在 10 的右子樹裡，不是 BST。正確做法有兩種：**中序遍歷檢查是否嚴格遞增**，或**往下傳遞上下界**（進左子樹時上界收緊為當前值，進右子樹時下界收緊為當前值）。

**詳細解析**：兩種做法各有細節。中序法只要維護「前一個訪問到的值」並比較是否嚴格遞增，空間是 O(h)；要注意**必須嚴格遞增**，相等值在標準 BST 定義中不合法，題目若允許重複則要先問清楚。上下界法要用可為空的型別或極值當初始邊界，用 `int` 的極值當哨兵在節點值本身就是極值時會出錯——這是個真實會被面試官挑出來的邊界。兩種做法都是 O(n)，選哪個看個人習慣，但能同時說出兩種並比較，比只會一種好。

**面試回答方式**：先用具體反例打掉「只比較父子」的錯誤解，這比抽象說明有力得多。接著給兩種正確解法（中序遞增、傳上下界）。加分點是主動提兩個邊界：要先問清楚是否允許相等值，以及用極值當初始邊界在節點值等於極值時會出錯。

### 二元樹的直徑為什麼遞迴回傳的值和答案不一樣？

**核心答案**：因為**能往上延伸的路徑不能分岔**。直徑是任意兩節點之間的最長路徑，在某個節點處它可以「左子樹下來、經過這個節點、再往右子樹下去」，形成一個拐點。但如果這條路徑還要往父節點延伸，就只能選左右其中一邊。所以遞迴**回傳**的是「以自己為端點往下的最長深度」（只能選一邊，取左右較大者加一），而**答案更新**用的是「左深度加右深度」（可以分岔）。

**詳細解析**：這個「回傳值與答案分離」的模式是樹形動態規劃的通用結構，一旦掌握就能解一整族題。最大路徑和是同一個模式的加強版——因為節點值可能為負，回傳時要對子樹結果取 `max(0, 子樹回報)`（負的就不要），更新答案時則是「當前值加左邊正貢獻加右邊正貢獻」。另一個變形是「最長同值路徑」，回報的是同值的單邊長度，答案是左右相加。面試中如果能把這三題說成同一個模式的變形，會顯得你掌握的是結構而不是題目。

**面試回答方式**：用「往上延伸不能分岔」這一句話解釋分離的原因，這是最核心的直覺。接著明確給出回傳值與答案更新式的差別。加分點是把最大路徑和、最長同值路徑歸為同一模式的變形，並提到最大路徑和要對負貢獻取零這個細節。

### 什麼時候該用 BFS 而不是 DFS 遍歷樹？

**核心答案**：**需要「層」的概念**，或需要**最短**的時候。求最小深度時 BFS 一碰到葉節點就能立刻回答，DFS 得走完整棵樹；每層最大值、右視圖、鋸齒層序這些天然按層的需求也只有 BFS 自然。反過來，需要子樹回報值的題（高度、直徑、路徑和）用 DFS 才順，BFS 拿不到「子樹整體」的資訊。

**詳細解析**：空間特性也是取捨的一部分。DFS 的空間是 O(h)，BFS 是 O(w)（最寬那一層的節點數）。對**細長的樹**（接近鏈狀），DFS 可能堆疊溢位而 BFS 只需要 O(1)；對**寬而淺的樹**（例如完全二元樹），DFS 只要 O(log n) 而 BFS 最後一層就佔了 n/2。所以沒有哪個一定省，要看樹的形狀。這個取捨在圖的遍歷上同樣成立，而且在圖上 BFS 還多一個關鍵優勢——在無權圖上 BFS 找到的第一條路徑就是最短路徑，DFS 沒有這個保證。

**面試回答方式**：給判準——要層或要最短用 BFS，要子樹回報用 DFS。接著補空間的取捨：DFS 是 O(高度)、BFS 是 O(最寬層)，細長的樹和寬淺的樹結論相反。加分點是延伸到圖：無權圖上 BFS 的第一條路徑就是最短路徑，這是 DFS 沒有的性質。
