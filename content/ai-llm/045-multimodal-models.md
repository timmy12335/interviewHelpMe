# 題目

多模態大模型是怎麼把圖片「送進」語言模型的？

## 核心答案

**核心思路是「把其他模態轉換成語言模型能吃的 token」**。

**主流的視覺語言模型分三個部件**。**視覺編碼器**——通常是一個預訓練好的 ViT（例如 CLIP 的視覺塔），**把圖片切成 patch 並編碼成一串向量**。**投影層（connector）**——**把視覺向量映射到語言模型的嵌入空間**；**可以是一個簡單的線性層或 MLP（LLaVA 的做法），也可以是更複雜的重採樣模組（Q-Former、Perceiver Resampler）**。**語言模型**——**把投影後的視覺 token 與文字 token 拼在一起，當成普通的序列處理**。

**訓練通常分兩階段**：**先凍結兩端只訓練投影層做對齊**（用大量圖文配對），**再解凍做指令微調**（用視覺問答類的資料教它遵循指令）。

**而關鍵的認知是「語言模型本身幾乎不需要改」**——**它只是收到了一些「來自圖片的 token」**。

## 詳細解析

**「視覺 token 數量」是這類模型的核心成本問題**。一張圖切成 patch 後可能產生幾百到幾千個 token——**而它們全部要進入語言模型的上下文並參與注意力計算**。**高解析度的需求讓這個問題更嚴重**：**要看清文件上的小字就需要更多 patch**。**兩種常見的處理**：**重採樣**（**用 Q-Former 或 pooling 把幾千個視覺 token 壓縮成固定的幾十到幾百個**——**省成本但丟細節**）、**以及動態解析度**（**按圖片內容決定切多細，並用切片加縮圖的組合兼顧細節與全局**）。**這個取捨直接決定了模型能不能讀懂表格與文件。**

**「凍結語言模型 vs 全部解凍」是訓練策略的關鍵取捨**。凍結——**保住原有的語言能力，訓練快、資料需求低**，**但視覺與語言的融合深度有限**。**解凍——融合更好但容易損害純文字能力**（**又是災難性遺忘**）。**實務上的折衷是「解凍但在訓練資料中混入大量純文字樣本」**——**這與微調時混入通用資料是完全相同的思路**。

**評估上有一個必須注意的陷阱**：**很多視覺問答的基準可以「不看圖也答對」**——**因為問題本身或選項透露了答案，或者答案是常識**。**所以評估多模態能力時應該包含「必須看圖才能回答」的案例**，**並用「把圖片換成空白後模型的正確率」作為對照**——**如果空白圖也能答對六成，那個基準的訊號就很弱**。

**其他模態的做法是同構的**：**音訊用 Whisper 這類編碼器、影片用「抽幀加時間編碼」**——**都是「編碼成向量再投影到語言模型空間」這個模式的變體**。**理解了這個模式，任何新模態的整合方式都可以推導出來。**

## 面試回答方式

先給核心思路——**把其他模態轉換成語言模型能吃的 token**，並說明三個部件與兩階段訓練，強調**語言模型本身幾乎不需要改**。加分點有四個：**視覺 token 數量是核心成本問題**——**一張圖可能產生幾百到幾千個 token 且全部參與注意力**，**兩種處理是重採樣（省成本但丟細節）與動態解析度**，**而這個取捨直接決定模型能不能讀懂表格與文件**；**凍結與解凍的取捨**——**解凍融合更好但損害純文字能力**，**折衷是混入大量純文字樣本，與微調時混入通用資料同一個思路**；**評估陷阱**——**很多視覺問答基準不看圖也能答對**，**應該用「把圖換成空白」作為對照**；以及**其他模態的做法是同構的**，**理解了這個模式就能推導任何新模態的整合方式**。

## 講稿

核心思路是把其他模態轉換成語言模型能吃的詞元。

視覺語言模型分三個部件。視覺編碼器把圖片切成小塊編碼成一串向量。投影層把這些向量映射到語言模型的嵌入空間。然後語言模型把投影後的視覺詞元跟文字詞元拼在一起，當成普通序列處理。關鍵的認知是語言模型本身幾乎不需要改，它只是收到了一些來自圖片的詞元。

訓練通常兩階段，先凍結兩端只訓投影層做對齊，再解凍做指令微調。

這類模型的核心成本問題是視覺詞元的數量。一張圖切完可能產生幾百到幾千個，全部要進上下文並參與注意力。而要看清文件上的小字就需要切得更細。所以有兩種處理，重採樣壓縮成固定的幾十到幾百個，省成本但丟細節，或者動態解析度，按內容決定切多細。這個取捨直接決定了模型能不能讀懂表格跟文件。

還有一個評估陷阱要注意。很多視覺問答的基準不看圖也能答對，因為問題本身透露了答案。所以應該用把圖片換成空白之後的正確率作為對照。

## 常見追問

### 為什麼有些模型讀不好文件與表格？

**核心答案**：**解析度不夠加上位置資訊丟失**。**解析度**——**如果圖片被縮到 336×336，一頁 A4 文件上的文字就糊了**；**這是很多早期模型的硬限制**。**位置資訊**——**表格的語義高度依賴行列的對齊關係**，**而把二維的 patch 序列展平成一維之後，那個結構部分丟失了**。

**詳細解析**：**現代模型的處理方式是「切片加全局縮圖」**：**把高解析度圖片切成多個子塊各自編碼（保留細節），同時附上一張縮小的全圖（保留佈局）**——**讓模型同時看到「局部的清晰」與「整體的結構」**。**這個做法讓文件理解的能力有了質的提升**。**但要說清楚代價：token 數暴增**——**一頁複雜文件可能消耗幾千個視覺 token**，**成本與延遲都顯著上升**。**所以在實際的文件處理場景中，「先用 OCR 加版面分析把文件轉成結構化文字，再用純文字模型處理」往往比直接餵圖給多模態模型更便宜也更準確**——**尤其是對標準格式的文件**。**能做出這個判斷，比熟悉多模態架構本身更有實務價值。**

**面試回答方式**：給兩個原因（解析度不夠、二維結構展平後丟失）並說明現代的**切片加全局縮圖**方案與它的代價（**token 數暴增，一頁複雜文件可能幾千個視覺 token**）。核心加分點是實務判斷：**在文件處理場景中，先用 OCR 加版面分析轉成結構化文字再用純文字模型，往往比直接餵圖更便宜也更準確**，**尤其對標準格式的文件**——**而能做出這個判斷比熟悉架構本身更有實務價值**。

### 多模態模型會「看錯」嗎？怎麼緩解？

**核心答案**：**會，而且它的幻覺有特定的模式**：**傾向於描述「常見的東西」而非「圖裡真正有的東西」**——**因為語言模型的先驗很強**。**典型例子是「圖裡是一個廚房，模型自動說有冰箱」，即使畫面裡並沒有**。**緩解的方式包括：在提示中要求「只描述你確實看到的」、要求指出物體的位置（迫使它真的定位）、以及對關鍵資訊做二次確認。**

**詳細解析**：**「語言先驗壓過視覺證據」是這類幻覺的根本機制**：模型在訓練中學到了「廚房通常有冰箱」這個強關聯——**當視覺信號較弱（圖片小、物體模糊、或視覺 token 被壓縮太多）時，語言先驗就佔了上風**。**這也解釋了為什麼「提高解析度」不只是看得清楚的問題，它同時增強了視覺證據相對於語言先驗的權重**。**在應用層面，最有效的緩解是「讓輸出可驗證」**：**要求模型給出邊界框或引用圖中的具體位置**——**一旦要指出「在哪裡」，編造的成本就大幅提高**。**這與 RAG 中「要求引用出處」降低幻覺是完全相同的機制**：**把一個開放的生成任務約束成一個可對照的任務。**

**面試回答方式**：給特定的幻覺模式（**傾向描述常見的東西而非圖裡真正有的**）與典型例子，給出緩解方式。核心加分點是解釋根本機制：**語言先驗壓過視覺證據**——**視覺信號較弱時先驗佔上風**，**這也解釋了提高解析度不只是看得清楚，它同時增強了視覺證據的相對權重**。收在最有效的緩解與它的普遍性：**要求給出邊界框或具體位置讓輸出可驗證**，**一旦要指出「在哪裡」編造的成本就大幅提高**——**與 RAG 中要求引用出處是完全相同的機制**。

### 影片理解與圖片理解差在哪？

**核心答案**：**多了「時間」這個維度，而它讓 token 預算問題急劇惡化**。一分鐘的影片按每秒一幀就是 60 張圖——**如果每張圖 256 個 token，就是 15000 個 token**。**所以影片模型的核心挑戰是「怎麼在有限的 token 預算內保留時間資訊」**：**稀疏抽幀、關鍵幀選擇、以及在時間維度上做池化。**

**詳細解析**：**「抽幀策略決定了能回答什麼問題」**：**均勻抽幀適合「這段影片大致在講什麼」**，**但會漏掉短暫發生的事件**（一個持續兩秒的動作在每 5 秒抽一幀的策略下可能完全看不到）。**場景切換偵測加關鍵幀是更好的做法**——**但它假設重要的事件伴隨畫面變化，而那未必成立**。**所以實務上「先用便宜的方式定位到相關片段，再對那個片段密集抽幀」是最有效的模式**——**這與 RAG 的「先粗召回再精排」是同一個結構**。**另一個常被忽略的是「音訊軌往往比畫面資訊量更大」**：**很多影片的關鍵資訊在旁白或對話裡**——**先做語音轉文字，用文字定位再看畫面，成本低得多也準得多**。**這個「先用最便宜的模態處理」的策略，往往比升級模型更有效。**

**面試回答方式**：指出**多了時間維度且它讓 token 預算急劇惡化**，用具體數字說明（一分鐘每秒一幀就是 15000 個 token），給三種處理。核心加分點是**抽幀策略決定了能回答什麼問題**——**均勻抽幀會漏掉短暫事件，場景切換假設重要事件伴隨畫面變化而那未必成立**，**所以「先定位相關片段再密集抽幀」最有效，與 RAG 的粗召回加精排是同一個結構**。收在常被忽略的一點：**音訊軌往往資訊量更大**，**先語音轉文字用文字定位再看畫面，成本低得多也準得多**。
