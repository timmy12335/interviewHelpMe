# 題目

微調之後模型原本會的東西變差了，為什麼？怎麼緩解？

## 核心答案

**原因是「梯度下降只優化你給的目標」**——**新資料的損失在下降，而模型並不知道要保住舊能力**。**參數被推向新任務的最優解，而那個位置對舊任務可能很差**。**微調的資料越窄、輪數越多、學習率越大，遺忘越嚴重。**

**五個緩解手段，按實用性排序**。**混入通用資料**——**在微調集中加入 10% 到 30% 的通用指令資料**，**最簡單也最有效**。**參數高效微調**——**LoRA 只改動少量參數，天然限制了偏離**。**降低學習率與輪數**——**多數遺忘來自訓練過頭**。**正則化到原模型**——**在損失中加入「與原模型輸出的 KL 散度」項**。**模型合併**——**訓練後把微調模型與原模型的權重按比例平均**。

**而前提是「你要能量測遺忘」**——**沒有通用能力的保留評估集，遺忘是完全不可見的。**

## 詳細解析

**「混入通用資料」為什麼這麼有效**：它把「保住舊能力」變成了訓練目標的一部分——**於是梯度下降會同時優化兩者，而不是只優化新任務**。**比例的選擇是一個取捨**：**通用資料太少擋不住遺忘，太多會稀釋新任務的學習信號**。**實務上從 20% 開始試，並用兩個評估集（目標任務與通用保留）觀察曲線**——**理想的停止點是「目標任務的收益開始遞減而通用能力尚未明顯下降」的地方**。

**「模型合併」是一個效果好得出乎意料的簡單方法**：**把微調後的權重與原始權重做加權平均**（`θ = α·θ_ft + (1-α)·θ_base`）——**得到的模型往往同時保留了大部分新能力與大部分舊能力**。**它有效的一個解釋是「微調通常只在原模型附近移動，兩者之間的權重空間是相對平坦的」**——**於是插值出來的點在兩個任務上都不差**。**這個方法幾乎沒有成本（不需要重新訓練），值得在任何微調之後試一試。**

**LoRA 的「天然抗遺忘」有一個額外的操作優勢**：**基礎模型完全沒有被改動，adapter 是可插拔的**——**於是你可以為不同任務訓練不同的 adapter，共用同一份基礎權重**，**推理時按需載入**。**這在服務多個垂直場景時，比維護多個全參數微調的模型省下巨大的儲存與部署成本。**

**「領域適配」與「行為微調」需要不同的策略**。**教模型新的領域知識**（醫學術語、公司內部概念）**需要更多資料與更大的參數改動**——**LoRA 在這裡可能不夠，需要繼續預訓練**。**而調整輸出格式與語氣只需要少量資料與 LoRA**。**選錯策略是微調失敗最常見的原因**——**用幾百條資料的 LoRA 想教會模型一個新領域，注定達不到預期**。

## 面試回答方式

先給原因——**梯度下降只優化你給的目標，模型不知道要保住舊能力**，並指出**資料越窄、輪數越多、學習率越大遺忘越嚴重**。給五個緩解手段並強調**前提是能量測遺忘**。加分點有四個：**混入通用資料為什麼有效**——**它把保住舊能力變成訓練目標的一部分**，並給比例的取捨與停止點的判斷；**模型合併效果好得出乎意料**——**權重加權平均往往同時保留新舊能力**，**解釋是微調只在原模型附近移動、兩者之間的權重空間相對平坦**，**而且幾乎沒有成本值得一試**；**LoRA 的可插拔優勢**——**共用基礎權重、按需載入 adapter，服務多場景時省下巨大成本**；以及**區分「領域適配」與「行為微調」**——**用幾百條資料的 LoRA 想教會新領域注定達不到預期，而選錯策略是微調失敗最常見的原因**。

## 講稿

原因是梯度下降只優化你給的目標。新資料的損失在下降，而模型並不知道要保住舊能力。參數被推向新任務的最優解，而那個位置對舊任務可能很差。

緩解手段裡最簡單也最有效的是混入通用資料。在微調集裡加一到三成的通用指令資料，它把保住舊能力變成訓練目標的一部分，於是梯度下降會同時優化兩者。比例我會從兩成開始試，用兩個評估集看曲線，停在目標任務收益開始遞減而通用能力還沒明顯下降的地方。

還有一個效果好得出乎意料的簡單方法，模型合併。把微調後的權重跟原始權重做加權平均，得到的模型往往同時保留大部分新能力跟大部分舊能力。它幾乎沒有成本，不需要重新訓練，值得在任何微調之後試一試。

但所有這些的前提是你要能量測遺忘。沒有一組通用能力的保留評估集，遺忘是完全不可見的。

最後一點，要區分教新領域知識跟調整輸出行為。前者需要更多資料跟更大的參數改動，後者少量資料加低秩微調就夠。選錯策略是微調失敗最常見的原因。

## 常見追問

### 繼續預訓練與微調怎麼選？

**核心答案**：**看你要加的是「知識」還是「行為」**。**繼續預訓練（CPT）**——**用領域的原始文本（無標註）繼續做下一詞預測**，**適合灌輸大量新知識**（醫學文獻、法律條文、公司文檔）；**需要的資料量是 GB 級**。**微調（SFT）**——**用指令與回應的成對資料**，**適合教任務格式與行為**；**幾千到幾萬條就有效果**。**完整的領域適配流程通常是「CPT 再 SFT」。**

**詳細解析**：**「CPT 的遺忘風險比 SFT 大得多」是一個重要的實務認知**：它改動的是模型的核心表示——**如果只用領域文本訓練，模型會迅速失去通用能力**。**所以 CPT 的資料配比通常是「領域資料加上相當比例的原始預訓練分布資料」**（常見是 1:1 到 1:3）。**另一個要點是「CPT 之後模型會退回成續寫模式」**——**因為它又只學了下一詞預測**，**所以必須再做一次 SFT 把指令跟隨的能力找回來**。**很多團隊在這一步踩坑：做完 CPT 發現模型「變笨了、不會回答問題了」，其實只是缺了後面那一步。** **能說出這個完整流程，通常表示真的走過一遍。**

**面試回答方式**：給選擇的判準（**知識 vs 行為**）與各自的資料形態與量級，並給出完整流程（CPT 再 SFT）。核心加分點是**CPT 的遺忘風險比 SFT 大得多**——**它改動核心表示，只用領域文本會迅速失去通用能力**，**所以配比通常是領域資料加相當比例的原始分布資料**。第二個是**CPT 之後模型會退回成續寫模式**，**必須再做一次 SFT 把指令跟隨找回來**——**很多團隊在這裡踩坑，以為模型變笨了，其實只是缺了後面那一步**。

### 怎麼知道模型「忘了」什麼？

**核心答案**：**建立一個固定的通用能力保留集，在微調前後各跑一次並比較**。內容應該涵蓋**與微調目標無關的多種能力**：常識問答、數學、程式碼、多語言、指令跟隨、以及安全拒絕。**關鍵是「這個集合在整個專案中保持不變」**——**只有固定的尺才能比較不同時間點的結果**。

**詳細解析**：**「安全拒絕能力的退化」是最容易被忽略卻最有後果的一種遺忘**：微調資料中如果全是「有求必應」的回應，**模型會學到「不要拒絕」——包括那些應該拒絕的請求**。**這在任何面向使用者的產品上都是嚴重的風險，而它在一般的能力基準上完全看不出來**。**所以保留集必須明確包含安全相關的測試案例**。**另一個實用的做法是「逐個檢查點評估」而非只評估最終模型**——**畫出「目標任務指標」與「保留集指標」隨訓練步數的兩條曲線**，**最佳的檢查點往往不是最後一個**，**而是兩條曲線交叉之前的某個點**。

**面試回答方式**：給做法（固定的通用保留集、前後比較、涵蓋多種無關能力）並強調**這個集合必須保持不變，只有固定的尺才能比較**。核心加分點是點出**安全拒絕能力的退化最容易被忽略卻最有後果**——**微調資料全是有求必應會讓模型學到不要拒絕，而這在一般能力基準上完全看不出來**。收在實用做法：**逐個檢查點評估而非只評最終模型**，**畫出兩條曲線，最佳檢查點往往不是最後一個**。

### 多個任務要微調同一個模型怎麼辦？

**核心答案**：**三種策略**。**混合訓練**——**把所有任務的資料混在一起訓練一個模型**；簡單，但任務之間可能互相干擾。**多 adapter**——**每個任務一個 LoRA，共用基礎模型，推理時按需載入**；**隔離乾淨，但需要知道當前請求屬於哪個任務**。**模型合併**——**分別訓練後把權重合併成一個**；**近年有不少方法（TIES、DARE）處理合併時的參數衝突**。

**詳細解析**：**「任務之間的干擾未必是壞事」值得指出**：**相關的任務混合訓練常常互相促進**（多任務學習的正遷移）——**例如同時訓練摘要與問答可能兩者都變好**。**所以混合訓練的第一步應該是實測而不是預設會干擾**。**真正需要隔離的是「目標明顯衝突」的任務**（例如一個要求簡潔、一個要求詳盡）。**至於多 adapter 的路由問題**：**如果請求類型可以由上游明確判斷（不同的 API 端點、不同的產品功能），路由就是免費的**；**而如果需要模型自己判斷，那反而增加了一層不確定性**——**這時混合訓練通常更務實**。**能把「技術選擇」連結到「上游是否有明確的任務標識」，是這題最實用的判斷。**

**面試回答方式**：給三種策略與各自的取捨。加分點是指出**任務之間的干擾未必是壞事**——**相關任務常常互相促進，所以第一步應該是實測而非預設會干擾**，**真正需要隔離的是目標明顯衝突的任務**。核心加分點是把選擇連結到工程現實：**多 adapter 的路由如果能由上游明確判斷就是免費的**，**而需要模型自己判斷反而增加一層不確定性**——**這時混合訓練通常更務實**。
