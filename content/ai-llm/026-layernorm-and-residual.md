# 題目

Transformer 裡的殘差連接與 LayerNorm 各自解決什麼問題？Pre-LN 與 Post-LN 差在哪？

## 核心答案

**殘差連接解決的是「梯度傳播」**：`x + f(x)` 讓梯度有一條直通的路徑回到淺層——**沒有它，幾十層的網路在反向傳播時梯度會消失或爆炸**。**它同時讓「什麼都不做」成為一個容易學到的解**，**於是加深網路至少不會變差**。

**層正規化解決的是「數值尺度」**：**把每個 token 的特徵向量正規化到零均值單位方差**（**注意是在特徵維度上，不是像 BatchNorm 那樣跨樣本**）——**讓每一層的輸入分布穩定，訓練不會因為尺度漂移而發散**。

**Pre-LN 與 Post-LN 的差別是「正規化放在殘差之前還是之後」**。**Post-LN（原始論文）**：`LN(x + f(x))`——**表現略好但訓練不穩定，需要 warmup 且對超參數敏感**。**Pre-LN**：`x + f(LN(x))`——**殘差路徑上完全沒有正規化，梯度可以無損地直通**，**訓練穩定得多**，**這是現代大模型的標準選擇**。

## 詳細解析

**「Pre-LN 的殘差路徑是乾淨的」是它穩定的根本原因**：Post-LN 中，**每一層的輸出都要經過一次正規化才傳給下一層**——**於是反向傳播時梯度要穿過 L 次正規化操作，累積的縮放讓深層難以訓練**。**Pre-LN 則讓 `x` 直接相加，梯度可以完全不衰減地回到第一層**。**代價是最後一層的輸出尺度會隨深度累積**，**所以 Pre-LN 架構通常在最後加一個 final LayerNorm。**

**為什麼不用 BatchNorm 值得說清楚**：**BatchNorm 跨樣本統計均值方差**——**而語言模型的序列長度不一、批次內差異大、推理時批次可能只有 1**，**這些都讓批次統計不可靠**。**LayerNorm 只在單個 token 的特徵維度上統計，完全不依賴批次**——**這讓訓練與推理的行為完全一致**，**是它適合序列模型的根本原因**。

**RMSNorm 是現代模型的簡化版**：**它去掉了減均值那一步，只做除以均方根的縮放**——**參數少、計算快，而實測效果與 LayerNorm 相當**。**LLaMA 系列開始它成為主流**。**這是一個「發現某個組件其實沒那麼必要」的典型例子**——**而這類簡化在大規模訓練中的價值很實在，因為它在每一層都省下計算**。

**殘差連接還有一個常被忽略的視角**：**它讓 Transformer 可以被理解成「一個殘差流（residual stream），每一層向它讀取並寫入資訊」**——**注意力層負責在 token 之間搬運資訊，前饋層負責在單個 token 內做變換**。**這個視角是可解釋性研究的基礎，也讓「為什麼可以剪掉某些層而模型仍然能用」變得可以理解**。

## 面試回答方式

先分別給兩者解決的問題——**殘差解決梯度傳播並讓「什麼都不做」成為容易學到的解**，**層正規化解決數值尺度且是在特徵維度而非跨樣本**。給 Pre-LN 與 Post-LN 的差別與現代的選擇。加分點有四個：**Pre-LN 穩定的根本原因是殘差路徑乾淨**——**Post-LN 的梯度要穿過 L 次正規化，而 Pre-LN 讓梯度無損直通**，**代價是輸出尺度隨深度累積所以要加 final LayerNorm**；**為什麼不用 BatchNorm**——**序列長度不一、推理時批次可能只有 1，批次統計不可靠**，**而 LayerNorm 完全不依賴批次讓訓練與推理行為一致**；**RMSNorm 去掉減均值那一步而效果相當**，是**「發現某個組件其實沒那麼必要」的典型**；以及**殘差流的視角**——**注意力在 token 之間搬運資訊、前饋在單個 token 內變換**，**這是可解釋性研究的基礎**。

## 講稿

殘差連接解決的是梯度傳播。輸入直接加上這一層的輸出，讓梯度有一條直通的路徑回到淺層。沒有它，幾十層的網路在反向傳播時梯度會消失或爆炸。它同時讓什麼都不做成為一個容易學到的解，所以加深至少不會變差。

層正規化解決的是數值尺度，把每個詞元的特徵向量正規化到零均值單位方差。注意是在特徵維度上，不是跨樣本。

現代模型都用前置的正規化而不是原始論文的後置。原因是前置讓殘差路徑完全乾淨。後置的話每一層輸出都要經過一次正規化才傳給下一層，反向傳播時梯度要穿過很多次正規化，累積的縮放讓深層難以訓練。前置則讓梯度完全不衰減地回到第一層。

還有一個值得說的，為什麼不用批次正規化。因為序列長度不一、批次內差異大、推理時批次可能只有一個，這些都讓批次統計不可靠。而層正規化只在單個詞元的特徵維度上統計，完全不依賴批次，訓練跟推理的行為完全一致。

## 常見追問

### 訓練發散或損失出現 NaN 怎麼排查？

**核心答案**：**按可能性排序檢查五項**。**學習率過高**（最常見——先把它降十倍看是否消失）、**沒有梯度裁剪**（**加上 global norm clipping**）、**混合精度的溢位**（**fp16 的動態範圍小，注意力分數容易溢位——換 bf16 或檢查 loss scaling**）、**資料裡的異常樣本**（**極長序列或損壞的 token**）、**以及正規化的實作問題**（**除以零、epsilon 太小**）。

**詳細解析**：**「fp16 vs bf16」值得展開，因為它是大模型訓練最常見的數值問題來源**：**fp16 的指數位只有 5 位，最大值約 65504**——**而注意力分數在長序列或大模型上很容易超過**；**bf16 的指數位有 8 位（與 fp32 相同），動態範圍大得多，代價是尾數精度較低**。**在訓練大模型時，bf16 幾乎總是更好的選擇**——**因為訓練對動態範圍的需求遠大於對精度的需求**。**這也是為什麼支援 bf16 的硬體（A100 之後）大幅簡化了大模型訓練**。**另一個實用的診斷是「記錄梯度範數的曲線」**——**發散前通常會先看到梯度範數的尖峰**，**而那個尖峰對應的資料批次往往就是問題所在**。

**面試回答方式**：給五項按可能性排序的檢查。核心加分點是展開 **fp16 與 bf16 的差別**：**fp16 指數位只有 5 位、最大值約 65504，注意力分數容易溢位；bf16 的指數位與 fp32 相同、動態範圍大得多，代價是尾數精度較低**，**而訓練對動態範圍的需求遠大於對精度的需求，所以 bf16 幾乎總是更好**。收在診斷技巧：**記錄梯度範數的曲線**——**發散前通常先看到尖峰，而那個尖峰對應的批次往往就是問題所在**。

### 為什麼前饋層要先擴大再縮小？

**核心答案**：**因為那是模型主要的「容量」所在**。前饋層典型的結構是 `d → 4d → d`——**中間的擴張提供了非線性變換的空間**。**參數量上它佔了 Transformer 的三分之二左右**（注意力只佔三分之一），**所以說「模型的知識主要存在前饋層」是有依據的**。**近年的 SwiGLU 等門控變體用三個矩陣取代兩個，並把中間維度調成約 8d/3 以保持參數量相當。**

**詳細解析**：**「前饋層是鍵值記憶體」是一個很有啟發性的理解**：**第一個矩陣可以看成一組「鍵」，計算輸入與每個鍵的匹配程度；第二個矩陣是對應的「值」，按匹配程度加權輸出**——**於是前饋層像是一個從輸入模式查詢對應知識的查表機制**。**這個觀點得到了不少可解釋性研究的支持**，**也解釋了為什麼模型編輯（直接修改某個事實）的方法多半作用在前饋層上**。**至於門控變體（SwiGLU）為什麼有效**：**額外的門控分支讓網路能「有選擇地」讓資訊通過**，**實測上在相同參數量下表現更好**——**這類改進沒有很強的理論解釋，主要是實驗驅動的，而這在當前的模型架構研究中相當常見**。

**面試回答方式**：給結構與參數佔比（**佔 Transformer 三分之二，所以「知識主要存在前饋層」是有依據的**）並提到 SwiGLU 的調整。核心加分點是**「前饋層是鍵值記憶體」的理解**：**第一個矩陣是鍵、計算匹配程度，第二個是值、按匹配加權輸出**，**這解釋了為什麼模型編輯的方法多半作用在前饋層上**。收在誠實的補充：**門控變體為什麼有效沒有很強的理論解釋，主要是實驗驅動的**——**而這在當前的架構研究中相當常見**。

### 能不能剪掉一些層？

**核心答案**：**可以，而且效果往往比預期好**——**尤其是中後段的層**。研究發現**深層 Transformer 的相鄰層之間輸出差異很小**，**移除其中一些對困惑度的影響有限**。**但要注意「困惑度影響小」不等於「能力不變」**——**推理與多步任務對層數的敏感度遠高於一般的語言建模**。

**詳細解析**：**這個現象與殘差流的視角一致**：**每一層都是在殘差流上做一個增量修改**——**而如果某些層的增量很小，移除它們的影響自然也小**。**這也解釋了「深度冗餘」為什麼存在：訓練並沒有強迫每一層都做出顯著貢獻。** **實務上的意義是「層剪枝是模型壓縮的一個可行方向」**，**但評估必須用能反映目標能力的基準而不是困惑度**——**因為困惑度主要由高頻的、容易的 token 主導**，**而那些正是最不需要深層計算的部分**。**這是一個很好的例子說明「選錯評估指標會得出完全錯誤的結論」**——**而這個陷阱在模型壓縮的各種方法上普遍存在**。

**面試回答方式**：回答可以且效果往往比預期好（尤其中後段），並給出原因——**深層 Transformer 相鄰層的輸出差異很小**，**這與殘差流的視角一致：每層只是做一個增量修改**。核心加分點是提出警告：**「困惑度影響小」不等於「能力不變」**——**推理與多步任務對層數的敏感度遠高於一般語言建模**，**而困惑度主要由高頻容易的 token 主導，那些正是最不需要深層計算的部分**。收在一般性的教訓：**選錯評估指標會得出完全錯誤的結論，而這個陷阱在模型壓縮的各種方法上普遍存在**。
