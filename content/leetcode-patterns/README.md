# LeetCode 範式（Java）

InterviewHelpMe 第 19 個內容類別，目前共 1 題。把資料結構、演算法與解題技巧整理成**可以直接默寫的 Java 範式**，每項附 1 到 3 題對應的 LeetCode 題目，並標出是否收錄在 NeetCode 150。

## 和「演算法與資料結構」類別的分工

[演算法與資料結構](../algorithms/README.md) 類別講的是**觀念與正確性論證**：什麼訊號讓你想到這個工具、它為什麼是對的。這個類別講的是**手要會寫的部分**：模板長什麼樣子、邊界條件怎麼寫、拿哪幾題練。兩邊每一頁都互相連結，建議先讀觀念再練範式。

## 每一頁的結構

沿用全站的題目格式，「詳細解析」固定包含：

- **範式**：一到三段 Java 程式碼，每段都實際編譯並跑過測資。
- **複雜度**：時間與空間。
- **常見錯誤**：寫模板時最容易出錯的邊界。
- **對應 LeetCode 題目**：表格列出題號、題名與連結、難度、是否在 NeetCode 150，以及用到哪一種範式。
