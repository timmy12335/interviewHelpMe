# 題目

用 Java 寫出位元運算的三個範式：用 XOR 讓成對的數抵消、用 `n & (n - 1)` 消去最低位的 1、用 `i >> 1` 推出位元計數的 DP，並說明它們對應哪些 LeetCode 題目。

## 核心答案

位元題靠的是幾個固定的恆等式。**XOR 的性質**：`a ^ a = 0`、`a ^ 0 = a`、滿足交換律，所以成對出現的數全部 XOR 會互相抵消。**`n & (n - 1)` 會把最低位的 1 變成 0**，迴圈做到 `n == 0` 的次數就是 1 的個數。**`n & -n` 取出最低位的 1**。**`i >> 1` 是 `i` 去掉最低位**，所以 `bits[i] = bits[i >> 1] + (i & 1)`。Java 要特別注意：`int` 是有號的 32 位元，邏輯右移用 `>>>`，算術右移 `>>` 會補符號位。

## 詳細解析

**範式一，XOR 抵消**：所有數 XOR 起來，出現兩次的都變成 0，只剩出現一次的那個。

```java
int singleNumber(int[] nums) {
    int x = 0;
    for (int n : nums) x ^= n;
    return x;
}
```

**範式二，消去最低位的 1**：每次 `n &= n - 1` 都少一個 1，迴圈次數等於 1 的個數，比逐位檢查 32 次快。輸入要當成無號數處理，所以條件寫 `n != 0` 而不是 `n > 0`。

```java
int hammingWeight(int n) {
    int count = 0;
    while (n != 0) {               // 負數也能正確結束
        n &= n - 1;
        count++;
    }
    return count;
}
```

**範式三，位元 DP**：`i` 的 1 的個數等於「去掉最低位後的數」的個數，加上最低位是不是 1。

```java
int[] countBits(int n) {
    int[] bits = new int[n + 1];
    for (int i = 1; i <= n; i++) bits[i] = bits[i >> 1] + (i & 1);
    return bits;
}
```

**常用小技巧**：檢查第 k 位 `(n >> k) & 1`；設第 k 位 `n | (1 << k)`；清第 k 位 `n & ~(1 << k)`；判斷是否為 2 的冪 `n > 0 && (n & (n - 1)) == 0`；枚舉 n 個元素的所有子集 `for (int mask = 0; mask < (1 << n); mask++)`。

```java
boolean isPowerOfTwo(int n) { return n > 0 && (n & (n - 1)) == 0; }
```

**複雜度**：XOR 抵消 O(n)、O(1) 空間；消去最低位是 O(1 的個數)，最多 32 次；位元 DP 是 O(n)。

**常見錯誤**：一是用 `n > 0` 當迴圈條件，輸入是負數（最高位為 1）時直接跳過。二是用 `>>` 逐位右移處理負數，符號位會一直補 1，變成無窮迴圈，要改用 `>>>`。三是運算子優先順序：`n & 1 == 0` 會被解析成 `n & (1 == 0)`，編譯不過，要加括號。

## 面試回答方式

先說出用到的恆等式，例如「XOR 自己是 0、XOR 0 是自己」，再寫程式。Java 的部分主動提有號整數與 `>>>`，這是很多人會漏的地方。位元題常被追問「不用額外空間」或「不用加法」，準備好 XOR 與 AND 的組合用法。

## 講稿

位元運算的題目，關鍵是記住幾個固定的性質。

第一個是互斥或。一個數跟自己做互斥或是零，跟零做互斥或是自己，而且順序不影響結果。所以只出現一次的數字那題，把全部的數做互斥或，成對的都抵消掉了，剩下的就是答案，不需要額外空間。

第二個是 n 跟 n 減一做且運算，會把最低位的那個一變成零。所以算有幾個一，就重複做這件事直到變成零，次數就是答案。Java 的整數是有號的，迴圈條件我寫不等於零，不寫大於零，負數才會算對。

第三個是位元的動態規劃。一個數右移一位，就是把最低位去掉，所以它的一的個數，等於右移後那個數的個數，再加上最低位是不是一，線性時間就能算完全部。

## 常見追問

### 如果每個數出現三次、只有一個出現一次呢？

**核心答案**：逐位統計：對 32 個位元各自計算所有數在該位的 1 的總數，對 3 取餘數，餘數就是答案在那一位的值。時間 O(32n)、空間 O(1)。

**詳細解析**：這是 LeetCode 137。更進階的寫法用兩個變數 `ones`、`twos` 模擬一個「模 3 的計數器」，但逐位統計比較容易在面試中寫對、也比較好解釋。最後組回答案時，第 31 位是 1 代表結果是負數，Java 的 `int` 會自動處理。

**面試回答方式**：先給逐位統計的解法，被追問時再提雙變數狀態機。

### 不用加號怎麼做加法？

**核心答案**：`a ^ b` 是不進位的和，`(a & b) << 1` 是進位，重複把兩者相加直到進位為 0。這是 LeetCode 371。

**詳細解析**：Java 的 `int` 溢位會自然回繞，所以負數也能正確處理，迴圈最多 32 次。Python 之類的無限精度整數就需要額外遮罩，這也是為什麼這題在 Java 裡相對簡單。

**面試回答方式**：說出「XOR 是無進位和、AND 左移是進位」這一句，再寫迴圈。

### 位元遮罩在什麼題目裡會用到？

**核心答案**：n 不大（通常 n ≤ 20）而需要表示「哪些元素被選了」的狀態時，用一個整數的各個位元表示集合，例如枚舉子集、狀態壓縮 DP、旅行推銷員問題。

**詳細解析**：`mask & (1 << i)` 判斷 i 是否在集合裡，`mask | (1 << i)` 把 i 加入。狀態壓縮 DP 的狀態數是 2^n，所以 n 超過 20 左右就不可行。LeetCode 78 Subsets 也可以用遮罩枚舉來解。

**面試回答方式**：說出 n 的規模限制，並舉子集枚舉為例。
